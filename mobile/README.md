# Domovoy — Android-оболочка

Тонкая нативная оболочка (Capacitor) над **живым UI дома**. Приложение НЕ содержит копию WebUI — оно
загружает тот же PWA, что раздаёт nginx, поэтому изменение UI не требует пересборки приложения. Это, по
сути, полноэкранный «урезанный браузер» с нативным слоем: онбординг адреса дома, выбор транспорта
(LAN→IPv6→SSH) и — в следующих итерациях — биометрический замок, уведомления и режим киоска.

Соответствует roadmap **Эпик 2O.3** (нативная обёртка) + **2O.3d** (менеджер подключения).

## Архитектура

```
Capacitor APK
 └─ www/ (бандл-лаунчер, единственное, что зашито в APK)
     ├─ index.html      онбординг + статус
     └─ connection.js   менеджер подключения: probe GET {origin}/health
                        приоритет LAN → IPv6-директ → SSH-fallback,
                        первый ответивший → window.location.replace(origin)
 └─ WebView после выбора транспорта показывает ЖИВОЙ UI дома (тот же PWA, same-origin)
```

Почему так: сервер-адрес выбирается **в рантайме** пользователем (у каждого дома свой LAN-IP / IPv6-хост /
VPS-домен), поэтому его нельзя зашить в сборку. Лаунчер решает, куда пойти, и передаёт WebView живому UI.

## Требования

- Node.js 20+
- Android Studio + Android SDK (Platform 34+), JDK 17
- Собранный/работающий бэкенд Домового с включённой аутентификацией (`JWTSETTINGS__ENABLED=true`) — см.
  `docs/mobile_app_remote_access_ru.md`.

## Сборка

```bash
cd mobile
npm install
npx cap add android      # создаёт папку android/ (нативный проект), один раз
npx cap sync             # копирует www/ + плагины в нативный проект
npx cap open android     # открыть в Android Studio → Run/Build APK
# или из CLI:
cd android && ./gradlew assembleDebug
```

APK ставится сайдлоадом (для self-hosted это удобнее, чем Google Play). Публикация в Play — опционально, позже.

## Настройка адресов при первом запуске

Онбординг спрашивает до трёх адресов; заполнять можно только те, что есть:

| Поле | Пример | Когда используется |
|---|---|---|
| Локальный (LAN) | `http://192.168.1.10` | дома, быстро, без интернета |
| IPv6 / внешний | `https://home.example.com` (AAAA) | основной удалённый доступ (см. Этап 3b) |
| Запасной SSH | `https://home.example.com` (через VPS) | когда IPv6 не добивает (см. Этап 3c) |

Приоритет проб — сверху вниз; первый, чей `/health` ответил 200 за 1.5 с, открывается в WebView.
