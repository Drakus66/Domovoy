# Domovoy Arduino Gateway Tasks Plan
Last Updated: 2025-05-09

## Обзор
Устройства Arduino будут использоваться как шлюзы (gateways) для подключения конечных устройств и трансляции данных по протоколу MQTT в основное приложение Domovoy.

## Подготовительные задачи
- [ ] Подготовить необходимые библиотеки (PubSubClient, WiFiManager, ArduinoJson и др.)
- [ ] Разработать общую архитектуру Arduino-шлюзов
- [ ] Определить стандартный формат сообщений для обмена данными с основным приложением
- [ ] Создать шаблоны скетчей для различных моделей Arduino (UNO, ESP8266, ESP32)

## Базовый MQTT-клиент
- [ ] Разработать базовый класс для подключения к MQTT-брокеру
- [ ] Реализовать функции публикации и подписки на топики
- [ ] Создать механизм автоматического переподключения к брокеру
- [ ] Добавить поддержку авторизации на MQTT-брокере

## Сетевое соединение
- [ ] Реализовать подключение по WiFi для ESP8266/ESP32
- [ ] Добавить функционал WiFi Manager для конфигурации без перепрошивки
- [ ] Реализовать сохранение настроек в EEPROM/Flash память
- [ ] Добавить индикацию статуса подключения (LED индикаторы)

## Gateway для различных типов устройств

### Gateway для сенсоров
- [ ] Разработать скетч для шлюза с датчиками температуры и влажности (DHT11/DHT22/BME280)
- [ ] Добавить поддержку датчиков движения (PIR)
- [ ] Реализовать поддержку датчиков освещенности (LDR/BH1750)
- [ ] Добавить поддержку датчиков качества воздуха (MQ135)

### Gateway для устройств управления
- [ ] Разработать скетч для управления реле/светодиодами
- [ ] Реализовать управление RGB-лентами
- [ ] Добавить поддержку управления сервоприводами
- [ ] Реализовать управление моторами

### Gateway для стандартных протоколов
- [ ] Добавить поддержку устройств Zigbee через CC2530/CC2531 модули
- [ ] Реализовать поддержку устройств 433MHz (приемник/передатчик)
- [ ] Добавить поддержку устройств ИК (приемник/передатчик)
- [ ] Реализовать поддержку устройств с протоколом 1-Wire (DS18B20 и др.)

## Удаленная конфигурация устройств
- [ ] Разработать механизм динамического назначения функций пинов через MQTT команды
- [ ] Создать систему сохранения настроек пинов в энергонезависимой памяти
- [ ] Реализовать JSON API для конфигурирования пинов ввода/вывода
- [ ] Добавить поддержку динамического назначения протоколов датчиков (I2C, SPI, 1-Wire)
- [ ] Создать интерфейс для динамической перенастройки параметров датчиков
- [ ] Разработать универсальный скетч с возможностью полной удаленной конфигурации

## Обнаружение и автоконфигурация
- [ ] Реализовать механизм автоматического обнаружения устройств (device discovery)
- [ ] Добавить поддержку Home Assistant MQTT Discovery
- [ ] Реализовать автоматическую регистрацию устройств в системе Domovoy
- [ ] Создать механизм обновления конфигурации устройств через MQTT

## Оптимизация и безопасность

- [ ] Реализовать механизм OTA-обновлений (Over-The-Air)
